### Few-shot prompt

In few-shot prompting the user provides the LLM with multiple examples. The approach shows the model a pattern that it needs to follow. This strategy is similar to **one-shot**, which provides the model with just one example. By providing multiple examples to the model it increases the likely hood of the LLM following the patterns identified in the examples.

### Use case

Not every task requires few-shot prompting. In general, it depends on a few factors, such as: the complexity of the task, the quality of the examples, and the capabilities of the GenAI model being used (i.e Gemini, Claude, ChatGPT, etc.)
